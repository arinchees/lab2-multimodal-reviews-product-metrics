## Данные и задача

Блокнот сам загружает таблицы `raw_review_All_Beauty` и `raw_meta_All_Beauty` из [Amazon Reviews 2023 на Hugging Face](https://huggingface.co/datasets/McAuley-Lab/Amazon-Reviews-2023), ревизия `749931181c9cdd70bfa6408d8fe8b4ddd6107248`. Три канала: текст отзыва, предыдущие оценки товара и изображение карточки. Цель — обнаруживать отзывы на 1–2 звезды; это **прокси жалобы**, а не ручная разметка обращений.

## Фактический результат запуска

Временные выборки: train 1200, validation 300, test 400. Основная метрика — macro-F1 на позднем test.

| Схема | Macro-F1 | AUROC | Brier |
|---|---:|---:|---:|
| Позднее слияние | 0,856 | 0,949 | 0,127 |
| Текст | 0,849 | 0,948 | 0,123 |
| Текст + история оценок | 0,848 | 0,921 | 0,116 |
| Текст + изображение | 0,815 | 0,923 | 0,128 |
| Раннее слияние всех каналов | 0,816 | 0,903 | 0,121 |
| История оценок | 0,640 | 0,717 | 0,186 |
| История оценок + изображение | 0,627 | 0,702 | 0,190 |
| Изображение | 0,506 | 0,541 | 0,216 |

Позднее слияние прибавило 0,0071 macro-F1 относительно текстовой модели, но 95% кластерный bootstrap-интервал разности равен [−0,0116; 0,0281], permutation test: `p = 0,2747`. Поэтому итоговая схема — **текстовая модель**. На test она пропустила 31 негативный отзыв из 120 и дала 18 ложных сигналов из 280 положительных; AUROC 0,948.

## Ограничения

Фото из метаданных — снимок карточки товара без даты появления. Эксперимент с ним ретроспективный и не доказывает пригодность для исторического online-прогноза. Рейтинг — шумная прокси жалобы. Временные части содержат общие товары; перенос на новые товары не проверялся. Денежные продуктовые метрики в данных отсутствуют; ошибки на 1000 отзывов являются операционными прокси. Сырые отзывы, фотографии, ASIN и идентификаторы пользователей в репозиторий не включены.
